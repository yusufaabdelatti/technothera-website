CUE

Session delivery and professional data collection, built for the moments that matter most.

CUE is a Progressive Web App designed around one job: helping ABA therapists deliver therapy sessions while collecting clinical data as quickly and accurately as possible — trial-by-trial data collection, behavior tracking, prompt fading, and progress monitoring, all in one screen, all working completely offline.

Clinical Depth

Built for real ABA practice

CUE supports the full range of ABA data collection a working therapist actually needs — every teaching methodology and every standard behavior measurement type.

Discrete Trial Teaching

Structured, trial-by-trial instruction with instant recording of each response.

Natural Environment Teaching

Flexible data capture for teaching that follows the child, not a script.

Task Analysis & Chaining

Step-by-step breakdowns for multi-step skills, tracked link by link.

Shaping & Prompt Fading

Prompt-level tracking across sessions to show fading progress clearly.

Behavior Measurement

Frequency, duration, latency, interval recording, and ABC data.

FBA & Functional Analysis

Dedicated tools for functional behavior assessment and analysis.

Preference Assessments

Structured tools for identifying and ranking effective reinforcers.

IOA & Training Records

Inter-observer agreement, plus staff and caregiver training documentation.

Offline-First, By Design

Runs entirely offline. No exceptions.

All clinical data is stored securely on the therapist's own device — no cloud database, no internet dependency during a session. For clinics running multiple therapists, devices can sync automatically over the clinic's own local network, so information stays current across the team without ever leaving the building.

  • No internet connection required to run a session, ever
  • All data stored securely on-device, under the therapist's control
  • Clinic devices sync automatically over the local network
  • No data ever needs to leave the building to stay current

Editions

CUE Lite. CUE Clinic.

CUE Lite

For Independent Therapists

Built for private practice — everything one therapist needs to run sessions and collect professional data, entirely offline.

  • Single-therapist license
  • Full trial-by-trial data collection toolkit
  • Secure on-device storage
  • Automatic progress graphs and PDF reports
CUE Clinic

For Multi-Therapist Clinics

Everything in CUE Lite, plus the coordination layer clinics need to run several therapists on one shared roster.

  • Role-based access for therapists and administrators
  • Automatic device sync over the clinic's local network
  • Centralized oversight for clinic administrators
  • Same clinical toolkit and reporting as CUE Lite
Note: Both editions run the same session and data-collection engine end to end. CUE Clinic adds the multi-therapist layer — role-based access and local network sync — for teams working across a shared caseload.
Scope Note

CUE is a focused clinical tool built for live therapy sessions — it is not a general clinic management system, not an EMR, and not a billing platform. It is built for the moments that matter most: therapist and child, in session, together.
