Platform Availability

Two applications. One framework.

Desktop App

Windows Native Application

A full-featured Windows application installed on the assessor's workstation. Runs entirely offline with no browser or internet dependency.

  • Windows 10 / 11 native install
  • Fully offline — no internet required after install
  • All six modules with full task sets
  • Local session storage and export
  • Clinician-controlled session flow
Tablet PWA

Cross-Platform Tablet App

A Progressive Web App optimised for tablet interaction. Works on iPads and Android tablets, offline after first load — no App Store required.

  • iPad and Android tablet optimised
  • Offline after first load — no install needed
  • Touch-native task interface
  • All six modules with identical scoring
  • Home screen installable (no App Store)
Important: Both applications run the same six modules with identical scoring formulas and produce the same clinical variables. They are independent products — not different tiers of one product. Your institution chooses the platform that fits its workflow.

Clinical Variables

Grounded in measurable output.

Every module produces named, documented clinical variables — not raw scores.

CFI
Cognitive Flexibility Index

Derived from Module 04 (Executive Cognitive Control). Measures the child's capacity to shift between cognitive sets and suppress prepotent responses.

MRS
Memory Reconstruction Score

Derived from Module 05 (VMR). Quantifies accuracy in spatial arrangement recall — distinct from simple recognition or verbal encoding.

WMI
Working Memory Index

Co-derived from Module 05 (VMR). Reflects the child's capacity to hold and manipulate spatial information over brief delay intervals.

ICA
Index of Concentration & Alertness

Derived from Module 01 (Attention & Concentration). Combines hit rate and false alarm rate into a single composite index of attentional control quality.

MUI
Memory Usage Index

Derived from Module 06 (Memory Integration). A cross-modal composite that normalises performance across visual and spatial binding tasks.

—
Session-Level Composites

When running multi-module assessments, the system computes session-level composite profiles that summarise cognitive performance across domains.

Clinical Note

The Cognitive Suite is a structured cognitive training and assessment tool — not a diagnostic instrument. It does not produce diagnoses, diagnostic classifications, or psychometric norm-referenced scores. Variables produced by the system are intended to support clinical observation, track intra-individual change over time, and inform — not replace — the clinician's professional judgement.
