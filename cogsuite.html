Six Structured Modules

One scoring system, one progress record per patient.

Attention & Concentration

Number-grid sequencing from 3×3 to 6×6 — tap numbers in ascending order, scored on speed and accuracy.

Reaction Time

Simple RT, Inhibition, and Choice RT modes, measuring raw speed, inhibitory control, and decision speed.

Visual Memory

Ten category columns, one highlighted item each — recall which item was shown per column after exposure.

Executive Control

Color/shape rule-switching with GO/NO-GO trials across three difficulty levels, measuring flexibility and inhibition.

Spatial Memory

Memorize a grid pattern, complete a math distractor, then reconstruct it from memory — three levels, up to 6×6.

Memory Integration

Card-matching across five levels up to an 8×8 grid, measuring working memory, encoding, and retrieval.
